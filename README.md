# 🍽️ Crispy — Food Recipes Collection

A community-driven collection of delicious food recipes, organized by category. Whether you're looking for a quick breakfast idea, a hearty dinner, or a sweet dessert, you'll find something here!

## 📁 Categories

| Category | Description |
|----------|-------------|
| [Breakfast](recipes/breakfast/) | Start your day right with morning favorites |
| [Lunch](recipes/lunch/) | Midday meals to keep you going |
| [Dinner](recipes/dinner/) | Hearty evening dishes for the whole family |
| [Desserts](recipes/desserts/) | Sweet treats and baked goods |
| [Snacks](recipes/snacks/) | Quick bites and appetizers |
| [Beverages](recipes/beverages/) | Drinks, smoothies, and more |

## 🚀 Getting Started

Browse the folders above to find recipes by category. Each recipe is a Markdown file with a consistent format including ingredients, instructions, and notes.

Want to add your own recipe? Check out the [recipe template](TEMPLATE.md) and the [contributing guidelines](CONTRIBUTING.md).

## 📝 Recipe Format

Every recipe follows a standard template:

- **Title** and short description
- **Prep time**, **cook time**, and **servings**
- **Ingredients** list
- **Instructions** (step-by-step)
- **Notes** and tips

See [TEMPLATE.md](TEMPLATE.md) for the full format.
